## Cómo recordar el proceso en el parcial
1. Leer el JSON y detectar si la respuesta es un objeto {} o una lista [].
2. Crear la data class con campos compatibles.
3. Declarar el endpoint con el verbo HTTP y la ruta.
4. Configurar Retrofit, su URL base y el convertidor.
5. Llamar al servicio desde Repository y ViewModel, usando una coroutine.
6. Mostrar los datos en la Activity y contemplar errores o carga.
